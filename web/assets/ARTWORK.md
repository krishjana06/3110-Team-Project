# Haunted Murder visual assets

- `estate-plan.svg`: a project-native architectural drawing with nine rooms, furniture outlines, doors, and corridors. Room hotspot coordinates in `web/app.js` correspond to this plan. It uses neutral charcoal surfaces; the UI adds the copper selection outline.
- `suspect-portraits.png`: original portraits generated with the built-in OpenAI imagegen tool on November 19, 2026. The atlas has three columns and two rows: Scarlet, Mustard, White; then Green, Peacock, Plum. CSS crops it for the roster and interviews.

The supplied reference screenshots informed the request for recognizable characters. No reference artwork is included in these assets.
